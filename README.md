# Wedding Website 💍

A responsive wedding website built with **Next.js, TypeScript, and CSS**, developed as a university Web Design project and used for a real wedding.

The application provides guests with wedding information and an interactive RSVP experience.

**Live Website:** https://site-nunta.vercel.app

## Features

- Responsive design for desktop and mobile devices
- Wedding event information
- Online RSVP functionality
- Interactive and user-friendly interface
- Live deployment on Vercel

## Technologies Used

- **Next.js** — React-based web framework
- **TypeScript** — Application development
- **JavaScript** — Web functionality
- **CSS** — Styling and responsive design
- **Git & GitHub** — Version control
- **Vercel** — Deployment and hosting

## Getting Started

To run this project locally:

**1. Clone the repository**

```bash
git clone https://github.com/denisamolnar/site-wedding.git
```

**2. Navigate to the project directory**

```bash
cd site-wedding
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

Some features may require environment variables to be configured locally.
